# ChainCadence

Runs decentralized, open-source software frameworks for blockchains on commodity hardware with minimal overhead costs.

With ChainCadence, you get a lightweight tool that stays out of your way.

**What you get**

- Runs decentralized, open-source software frameworks
- for blockchains on commodity hardware
- with minimal overhead costs

## Key Features

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainCadence.git`
2. `cd ChainCadence`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
